# Used Car Market Analysis

## Project 1 – Exploratory Data Analysis (EDA)

**Objective:** Explore used car advertisement data and create visualizations to analyze vehicle prices, mileage, and relationships between variables.

**Activities:**
- Explored and analyzed the dataset using Pandas.
- Created histograms to visualize data distributions.
- Developed scatter plots to identify relationships between vehicle characteristics.
- Used Plotly Express to create interactive visualizations.
- Created a Jupyter Notebook (`EDA.ipynb`) to document the analysis.
- Set up a Python virtual environment.

**Libraries:** Python, Pandas, Plotly Express, Jupyter Notebook.

## Project 2 – Interactive Web Application

**Objective:** Develop an interactive web application to visualize and explore used car advertisement data.

**Activities:**
- Built a web application using Streamlit.
- Integrated interactive data visualizations.
- Used Pandas for data handling and Plotly Express for charts.
- Published the application on Render and uploaded the project to GitHub.

**Libraries:** Python, Pandas, Plotly Express, Streamlit.
